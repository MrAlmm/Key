# NIRVANA TWEAK - Key Server

سيرفر بسيط يتحقق من مفاتيح التفعيل ويمنع استخدام نفس المفتاح على أكثر من جهاز.

## كيف يشتغل؟
- عندك 200 مفتاح جاهزين بملف `keys.json`
- البرنامج (C++) يرسل المفتاح + Hardware ID للسيرفر عند التشغيل
- أول مرة يُستخدم فيها المفتاح، ينقفل على ذلك الجهاز (hwid) ولا يشتغل على جهاز ثاني
- نفس الجهاز يقدر يرجع يستخدم نفس المفتاح لاحقاً بدون مشاكل (auto-login)

## رفع السيرفر مجاناً على Render.com

1. روح لـ https://render.com وسوي حساب مجاني (تقدر تسجل بـ GitHub)
2. ارفع هذا المجلد كامل (`key-server`) لمستودع GitHub جديد (خاص - Private أفضل عشان محد يشوف المفاتيح)
3. من لوحة تحكم Render: **New** → **Web Service**
4. اربطه بمستودع GitHub يلي رفعته
5. الإعدادات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
6. اضغط **Create Web Service** وانتظر شوي لين يخلص النشر
7. بعد ما يخلص، بيعطيك رابط زي:
   ```
   https://nirvana-key-server.onrender.com
   ```
   هذا هو الرابط يلي بتحطه بكود C++ بمكان `SERVER_URL`

## ملاحظة مهمة
النسخة المجانية من Render "تنام" لو ما فيه طلبات لمدة 15 دقيقة، وأول طلب بعد النوم ياخذ كام ثانية إضافية لين يصحى. هذا طبيعي بالخطط المجانية. لو تبي سرعة دائمة، فيه خطط مدفوعة رخيصة (من 7$ شهرياً).

## أمان
- ملف `keys.json` هو قلب النظام. لا ترفعه بمكان عام (public repo) أو يقدر أي حد يشوف كل المفاتيح.
- لو ضاعت/تسربت المفاتيح، تقدر تولّد دفعة جديدة بتشغيل سكربت التوليد مرة ثانية وتستبدل الملف.
